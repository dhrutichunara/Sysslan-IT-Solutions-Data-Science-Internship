# 🚆 Sysslan IT Solutions – Data Science Internship

## 📌 Project Title

**Train Route Analysis and Journey Time Prediction**

## 📖 Overview

This repository contains my Data Science Internship project completed at **Sysslan IT Solutions**. The project demonstrates the complete Data Science workflow, including data preprocessing, exploratory data analysis (EDA), visualization, feature engineering, and machine learning.

The objective of the project is to analyze train route data and build a **Linear Regression** model to predict train journey duration based on important features such as total distance and number of stops.

---

## 🎯 Objectives

* Understand and inspect the dataset
* Clean and preprocess the data
* Perform Exploratory Data Analysis (EDA)
* Visualize trends and patterns
* Engineer useful features
* Build a Linear Regression model
* Evaluate model performance
* Develop a journey time prediction system
